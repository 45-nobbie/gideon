# Gideon

**Sir Gideon, the All-Knowing — your command-line companion.**

Gideon is a CLI tool that helps you discover Linux commands using natural language, understand existing commands, search manual pages, and save frequently used commands for later.

## Installation

Download the `gideon` binary from the project's release page.

Make it executable:

```bash
chmod +x gideon
```

Run Gideon:

```bash
./gideon --help
```

The standalone binary targets **Linux x86-64** and does not require a separate Python installation.

## Commands

### 1. `hello` — Summon Gideon

Display Gideon's greeting.

```bash
gideon hello
```

### 2. `howto` — Generate commands from natural language

Describe what you want to do, and Gideon will suggest a command.

```bash
gideon howto "show hidden files"
gideon howto "find files ending in .log"
gideon howto "search recursively for TODO"
```

You can specify a shell with `--shell` or `-s`:

```bash
gideon howto "find files ending in .log" --shell bash
```

### 3. `explain` — Understand a command

Break down a supported command and its arguments.

```bash
gideon explain "grep -in ERROR app.log"
gideon explain "ls -la"
gideon explain "find . -type f"
```

### 4. `ofnir` — Read a manual page

Read an installed Linux manual page.

```bash
gideon ofnir ls
gideon ofnir grep
gideon ofnir find
```

Manual pages must be available on your system.

### 5. `search` — Search manual pages

Search installed Linux manual pages for a topic.

```bash
gideon search network
gideon search files
gideon search process
```

### 6. `save` — Save a command

Store a command under an alias for future reference. **Saving a command does not execute it.**

```bash
gideon save "printf 'Hello from Gideon\n'" --as greeting
gideon save "ls -la" --as list-files
```

The `--as` option specifies the alias.

### 7. `saved` — List saved commands

Display your saved commands.

```bash
gideon saved
```

### 8. `show` — Display a saved command

Display a saved command by its alias without executing it.

```bash
gideon show greeting
gideon show list-files
```

### 9. `forget` — Delete a saved command

Remove a saved command by its alias.

```bash
gideon forget greeting
```

### Getting help

View the available commands and global options:

```bash
gideon --help
```

View help for a specific command:

```bash
gideon howto --help
gideon explain --help
gideon ofnir --help
gideon search --help
gideon save --help
gideon saved --help
gideon show --help
gideon forget --help
```

## Development

To run Gideon from the source repository:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

Run the test suite:

```bash
pytest -v
```

## Notes

- Gideon suggests commands; it does not execute commands generated by `howto` or displayed by `show`.
- Always review a suggested command before running it yourself.
- Command recognition and explanations are limited to supported requests and patterns.
- Manual-page features depend on the documentation available on your Linux system.
- The beta binary is intended for Linux x86-64.
